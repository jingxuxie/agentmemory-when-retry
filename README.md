# Retry, Inspect, or Roll Back?

## Work-Resolution Limits for Agent Recovery

Research repository for a theory-first, CPU-only study of hidden-fault checkpoint recovery. The complete local draft, proofs, synthetic experiment code, and results are being added in the following research commit.

The work uses no language-model API calls, no training, and no GPU. The draft is not submitted and has not received independent proof or novelty review.
